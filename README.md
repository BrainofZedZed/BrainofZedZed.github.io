# Zachary Zeidler — personal research website

Static site served by GitHub Pages from the main branch root.

- `index.html` — the whole site on one page: opening section, research directions, featured research, expertise, selected publications, about, contact.
- `publications.html`, `research.html`, `about.html` — redirects to the matching homepage sections so old links still work.
- `styles.css` — layout and design tokens. `site.js` — image enlarge dialog and active-section nav.

Original scientific images are provided by Zachary Zeidler. Asset paths are relative.
