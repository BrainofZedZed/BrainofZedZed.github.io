# Zachary Zeidler — personal research website

Static site served by GitHub Pages from the main branch root.

- `index.html` — homepage: hero, highlights, featured research, research directions, earlier findings, expertise, about, contact.
- `publications.html` — full publication list, led by the bioRxiv paper (revised and resubmitted, Nature Neuroscience).
- `research.html`, `about.html` — redirects to homepage sections so old links still work.
- `styles.css` — all layout and design tokens. `site.js` — image enlarge dialog and active-section nav.

Original scientific images are provided by Zachary Zeidler. Asset paths are relative.
