bioRxiv · Preprint / revised research summary

Memory consolidation

How new neurons join a lasting memory

I identified a class of prefrontal projection neurons that are gradually recruited into a memory trace through the synaptic activity of learning-activated cells. This population, which projects to the temporal association area (TEa), progressively strengthens its encoding of memory-related behavior and becomes necessary for remote recall. Whole-brain mapping revealed that the same neurons send prominent branches to the claustrum. Both target regions show increased tone-evoked responses during consolidation, yet exhibit distinct response dynamics. Inhibiting the two branches has opposing effects on remote recall. These findings reveal a cell-type-specific mechanism of memory reorganization in which one prefrontal population distributes evolving signals across functionally distinct cortical targets.

Directed cell-type recruitment during consolidation of a remote memory

Current Biology

Dopamine & learning

Learning actions that prevent threat

Dopaminergic input to the prefrontal cortex is required for rapid avoidance learning, but not for recalling an established strategy. Dopamine signals increased with aversive outcomes and decreased with successful avoidance; these dynamics differed when animals experienced matched outcomes without behavioral control.

Dopaminergic projections to the prefrontal cortex are critical for rapid threat avoidance learning

Springer · Book chapter

A perspective on memory

Rethinking the enduring memory trace

This chapter brings together evidence for the changing cellular and circuit organization of prefrontal memory ensembles. We examine what these findings mean for systems consolidation and engram theories, and how dynamic neuronal participation can support persistent memories.

eLife · Tools & resources

Open-source software & hardware

Making behavioral experiments more accessible

I co-developed BehaviorDEPOT, an open-source MATLAB toolbox for detecting and analyzing behavior from markerless pose tracking. The project integrates analysis tools with an Arduino-based experiment-control module, reflecting my interest in building accessible software and hardware for reproducible neuroscience.

Disease-relevant animal models

Connecting hippocampal pathology to behavior

I developed and characterized a ventral hippocampal mouse model of temporal lobe epilepsy, comparing seizure, cognitive, and affective outcomes with the dorsal model. This work established my experience connecting disease-relevant circuit pathology to memory and affective behavior.
